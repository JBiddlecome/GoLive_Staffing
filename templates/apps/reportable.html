Reportable

Reportable is a planned Python data exporter for MariaDB on Render. It will connect to AWS RDS, let users choose tables/columns and date ranges, and generate downloadable Excel files.

Planned capabilities

  • Secure MariaDB connection (hosted in AWS RDS) using environment variables for secrets.
  • Automatic schema discovery with SHOW TABLES; and DESCRIBE <table_name>;.
  • Date range filtering against timestamp fields such as created_at.
  • Column-level selection and export to .xlsx via pandas + openpyxl.
  • Schema reference grounded in database_schema.md from this repository.
