Microsoft 365 Setup Required

To fetch user emails, the application uses the Microsoft Graph API. As a global admin, please ensure you have registered a Microsoft Entra ID App with Application Permissions for Mail.Read (and granted Admin Consent). The backend environment variables O365_TENANT_ID, O365_CLIENT_ID, and O365_CLIENT_SECRET must be set.
